# 💼 Job Recruitment Management System

A modern, responsive, and fully functional job recruitment management platform built with **PHP**, **SQL**, **JavaScript**, and **CSS**. Designed to streamline the job application process for both **applicants** and **administrators**.

---

## 🚀 Features

### 🛠️ Admin Dashboard
- Add, edit, delete jobs with real-time search
- Approve, reject, or view job applications
- Real-time application status updates
- Application analytics & charts
- Manage users and job history
- Email notifications for approved/rejected applicants
- Personalized admin panel with full navigation:
  - Job Management
  - Application Tracking
  - Analytics
  - User Management

### 👨‍💼 User Dashboard
- Apply to jobs with uploaded CVs (not stored in DB)
- Track application status
- Personalized job recommendations
- Update profile and view application history
- Attractive, mobile-responsive design

---

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Design:** Responsive layout, modern UI/UX  
- **Extra:** Email automation for notifications
